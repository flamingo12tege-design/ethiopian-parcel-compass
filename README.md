# Remix of Remix of Remix of Ethiopian Parcel Tracker

Recreate the attached Ethiopian Postal Service parcel tracking app UI as a functional, responsive mobile-first application.

Use the attached image as the primary visual reference. Match its navy blue header, yellow accents, white backgrounds, rounded cards, parcel illustrations, typography, bottom navigation, and clean layout.

Build these screens:

Home dashboard with tracking number search.

Track Parcel screen.

Tracking Details screen with parcel status and a vertical event timeline.

Parcel Details screen.

Send Parcel multi-step form.

Post Office Locator screen.

Notifications screen.

Profile and settings screen.

Requirements:

Make all navigation, buttons, forms, and tracking searches functional.

Use reusable React and TypeScript components.

Use Supabase for persistent data and authentication.

Start with clearly labelled fictional demo parcel records.

Prepare the application for Capacitor Android integration.

Plan native push notifications using Firebase Cloud Messaging when a parcel status changes.

Implement secure server-side notification sending and prevent duplicate notifications.

Do not pretend demo parcel movements are real.

Keep the design close to the reference image while making every screen usable on a real phone.

First implement the complete UI and working navigation. Then connect the database and tracking workflow. Finally prepare the native notification integration and document the setup steps.
